
# 🎥 Leerlijn Animatie 3

## 📆 Periode 1 – Narratief & Tijd

**Duur:** 01-09-2025 t/m 03-11-2025
**Doel:** De student leert een kort narratief animatieproject opbouwen met focus op timing, visuele stijl en camera.

| Week           | Thema                         | Lesinhoud / Techniek                                       | Opdracht                                               | Beoordeling |
| -------------- | ----------------------------- | ---------------------------------------------------------- | ------------------------------------------------------ | ----------- |
| 1              | Intro: Motion Design & AE     | Basisinterface After Effects, keyframes, easing, precomps  | Oefening: maak een bouncing ball met AE                |             |
| 2              | Timing & Narratieve Structuur | Storytelling in animatie, camera in AE, tempo vs timing    | Analyse: dissecteer openingsscene uit een animatiefilm |             |
| 3              | Storyboarding & Animatic      | Shotplanning, layerstructuur, sound sync, AE audio markers | Storyboard + animatic maken in AE                      | 5/10        |
| 4              | Character Rigging             | Puppet pins, DUIK Bassel, parenting, motion paths          | Eenvoudige character loop in AE                        |             |
| 5              | Camera & Diepte               | 2.5D compositing, camera tracking, parallax effect         | Maak een loopende scene met diepte                     |             |
| 6              | Titel & Typografie            | Text animators, kinetic type, motion blur                  | Titel + intro-sequentie ontwikkelen                    |             |
| Herfstvakantie |                               |                                                            |                                                        |             |
| 7–8            | Werkfase eindproject          | Start korte animatie (20–30 sec), feedbackmoment           | Verhaal afwerken, kleurcorrectie en audio toevoegen    |             |
| 9              | Render & Compositie           | Output modules, exporteren voor web/presentatie            | Final render + thumbnails voor presentatie             |             |
| Schakelweek            | Screening & Reflectie         | Peer review, groepsscreening, pitch eigen project          | Presentatie + reflectie                                | Cijfer      |

## 🎨 Periode 2 – Autonoom & Onderzoekend

**Duur:** 18-11-2025 t/m 30-01-2026
**Doel:** De student experimenteert met stijl en techniek via een autonoom motion graphics-project.

| Week          | Thema                         | Lesinhoud / Techniek                                                | Opdracht                                     | Beoordeling |
| ------------- | ----------------------------- | ------------------------------------------------------------------- | -------------------------------------------- | ----------- |
| 1             | Persoonlijke Stijl & AI Tools | Exploratie stijl/mood, AI beeldgeneratie, AE + Photoshop integratie | Visueel moodboard + referentieanalyse        |             |
| 2             | Experiment: Glitches & Loops  | Displacement maps, expressions, seamless loops, time remapping      | Maak 3 experimentele loops (5 sec elk)       |             |
| 3             | Typografische Animatie        | Text animators, per-character animation, motion curves              | Korte typografische sequence met voice-over  |             |
| 4             | Scripting & Automatisering    | Simple expressions, time, loopOut, wiggle                           | Herbruikbare preset maken met automatisering | 5/10        |
| 5             | Compositing & Masking         | Green screen, rotobrush, track mattes, blending modes               | Collage-animatie met gevonden video/foto’s   |             |
| 6             | Projectvoorstel & Start werk  | Pitch projectplan, technische haalbaarheid, research                | Begin autonome animatie (30–45 sec)          |             |
| Kerstvakantie |                               |                                                                     |                                              |             |
| Kerstvakantie |                               |                                                                     |                                              |             |
| 7             | Feedbackronde                 | Class review, revisie in AE, optimalisatie                          | Verbeter animatie o.b.v. feedback            |             |
| 8             | Finaliseren & Output          | Exporteer voor social/video/print, preview render                   | Eindversie + teaser maken voor presentatie   |             |
| Schakelweek   | Screening & Reflectie         | Groepsscreening, logboek, procesreflectie                           | Presentatie + eigen stijlboek/handleiding    | Cijfer      |
